# SunuShop Fashion

SunuShop Fashion est un site e-commerce dédié à la mode, développé avec **HTML, CSS et JavaScript**.

Le projet permet aux utilisateurs de découvrir une collection de vêtements, chaussures et accessoires, de consulter les détails des produits et de gérer leurs favoris et leur panier.

## Fonctionnalités

* Page d'accueil moderne
* Catalogue de produits
* Recherche de produits
* Filtrage par catégorie
* Tri des produits
* Pagination du catalogue
* Collections de produits
* Page détaillée des produits
* Gestion des favoris
* Gestion du panier
* Ajout et suppression de produits du panier
* Gestion des quantités
* Sauvegarde du panier et des favoris avec `localStorage`
* Page de commande
* Page de contact
* Design responsive

## Technologies utilisées

* **HTML5** — structure des pages
* **CSS3** — mise en forme et responsive design
* **JavaScript** — interactions et fonctionnalités dynamiques
* **Font Awesome** — icônes
* **LocalStorage** — sauvegarde des données côté navigateur
* **Git & GitHub** — gestion du projet et versionnement

## Installation et utilisation

### 1. Cloner le projet

```bash
git clone https://github.com/ramatoulayedaffe0308-cell/SunuShop-Fashion.git
```

### 2. Accéder au dossier

```bash
cd SunuShop-Fashion
```

### 3. Lancer le projet

Ouvrir `index.html` dans un navigateur.

Pour une meilleure expérience de développement, il est recommandé d'utiliser **Live Server** avec Visual Studio Code.

Ce projet a été réalisé dans le but de mettre en pratique les connaissances en **développement web frontend**, notamment :

* la structuration d'un site avec HTML ;
* la création d'interfaces avec CSS ;
* la manipulation du DOM avec JavaScript ;
* la gestion des événements ;
* l'utilisation de `localStorage` ;
* la création d'un système de panier et de favoris ;
* l'organisation d'un projet web ;
* l'utilisation de Git et GitHub.
